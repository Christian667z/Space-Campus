# Les Origines de Python

## La fin des années 1980

À la fin des années 1980, le développement logiciel devenait de plus en plus complexe.

Les langages populaires de l’époque comme :
- C,
- C++,
- Pascal,
- Perl,

étaient puissants, mais souvent difficiles à lire et à maintenir.

Beaucoup de développeurs recherchaient :
- un langage plus simple,
- plus lisible,
- plus rapide à développer,
- tout en restant puissant.

C’est dans ce contexte que Python est né.

---

# Le Créateur : Guido van Rossum

Python a été créé par Guido van Rossum, un développeur néerlandais travaillant au :
- CWI (Centrum Wiskunde & Informatica),
- le Centre de Mathématiques et d’Informatique des Pays-Bas.

Guido travaillait sur un projet appelé :
- ABC Programming Language.

ABC était un langage conçu pour être simple et éducatif, mais il possédait plusieurs limitations.

Guido voulait créer un nouveau langage qui :
- conserverait la simplicité d’ABC,
- mais serait plus flexible,
- plus puissant,
- et extensible.

# Pourquoi le nom "Python" ?

Contrairement à ce que beaucoup pensent, le nom Python ne vient pas du serpent.

Le nom vient de l’émission humoristique britannique :

```text
Monty Python’s Flying Circus
```

Guido van Rossum était fan de cette émission et voulait un nom :
- court,
- unique,
- mystérieux,
- facile à retenir.
