# Les 5 'V' du Big Data

**Difficulté :** ★★★★★☆☆☆☆☆

## Théorie
Le Big Data se caractérise traditionnellement par 5 dimensions (les 5 V) : Volume (quantité massive), Vélocité (vitesse de génération), Variété (données structurées, non structurées), Véracité (fiabilité des données), et Valeur (utilité extraite).

## Points Clés
- Hadoop & Spark : Outils phares pour le traitement de gros volumes.
- Données non structurées : Vidéos, tweets, logs, qui ne rentrent pas dans un tableau SQL classique.

> **⚠️ Piège Prof :** Confondre une base de données relationnelle classique (SQL) et un écosystème Big Data (NoSQL / Hadoop) qui scale horizontalement.
