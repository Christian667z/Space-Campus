Asta Académie - Aide Hors-Ligne

Bienvenue dans le centre d'aide hors-ligne d'Asta Académie.

1. Comment utiliser le SpaceCode ?
Pour utiliser SpaceCode :
- Rendez-vous dans l'onglet "SpaceCode".
- Choisissez un template dans le menu déroulant en haut.
- Modifiez le code.
- Cliquez sur "▶ Run Python" pour exécuter un script Python, ou "🌐 Aperçu HTML" pour voir le rendu Web.

2. Je n'arrive pas à me connecter (Licence expirée ou bloquée)
Si votre licence indique "NON" ou est bloquée :
1. Assurez-vous d'avoir entré la bonne clé.
2. Vérifiez si votre abonnement ou votre paiement a été validé par le professeur.
3. Contactez l'administrateur système (Lucky Luke).

3. Où sont sauvegardées mes notes ?
Vos notes, votre profil et vos scores sont sauvegardés dans le dossier d'installation que vous avez choisi lors du premier lancement, sous le dossier `config/` et `database/`. 
"Ne supprimez jamais le dossier `database/` ou `config/`", sinon vous perdrez toute votre progression !

4. Que faire en cas de crash ?
Si l'application se ferme brusquement, un rapport d'erreur est automatiquement généré dans le dossier `logs/app.log`. Vous pouvez envoyer ce fichier au développeur pour corriger le problème. Le numero whatsaap du développeur est +509 46 96 6290 vous pouvez envoyez un mail sur teamtecnodev@gmail.com !

5. Que faire si vous voulez partager votre connaissance avec le développeur ?
Vous pouvez aidez l'administrateur du système et le créateur du project (Lucky Luke) à améliorer l'application, si vous avez des idées pour améliorer le logiciel, partager vos connaissances pour nos chers étudiants en informatique ou encore faire partie de l'équipe de (Space) contacté +509 35 67 2037 /+509 46 96 6290 et le développeur vous donnerons les marches à suivre.
